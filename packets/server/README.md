# Server dastur: internetsiz o'rnatish to'plami

Hozircha bo'sh. Server dastur (`server/`) Linux'da Docker ichida ishlaydi, shuning uchun bu yerga
Windows `.whl` lari emas, Linux paketlari va Docker image'lari (`docker save`) kerak bo'ladi.
Bundan tashqari, server Claude API bilan ishlaydi, demak unga baribir internet kerak.
